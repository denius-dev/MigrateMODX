MigrateMODX
===========

Guided migration from MODX Revolution 2.6.5–2.8.x to MODX 3 with:

- Package compatibility map and alternatives
- PHP 7.4 → 8+ prep (scan + safe autofix)
- Template syntax scan (MODX/pHx + Fenom)
- Snapshots and rollback
- Standalone Recovery Console when the manager is down

Install via Package Management, then open Packages → MigrateMODX.
