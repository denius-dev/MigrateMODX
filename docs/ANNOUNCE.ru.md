# MigrateMODX — анонс (черновик)

MigrateMODX — CMP-префлайт перед апгрейдом PHP на MODX 2 или переездом на MODX 3. Не «несколько кликов до готового сайта» и не замена соседнему инстансу тройки + агенту + плейбукам.

Две цели в вкладке «Переезд»: остаться на двойке и вычистить PHP 8.x, либо идти на тройку фазами (подготовка → ядро 3.0.0 → setup → при ms2 уже на 3 поставить MiniShop3 и данные). Attention Report — инвентарь known/unknown для рук или агента, не вердикт «сайт разобран». Snapshot и Recovery — страховка до наката.

**Кому:** студии с пачкой 2.x / ms2 и тем, кто хочет детерминированный чеклист до агента. Кому хватает соседнего MODX 3 и плейбука — можно без компонента.

**FAQ.** Без агента в несколько кликов сложный сайт не переедем. Компонент не умнее агента: матрица пакетов, Recovery, gate перед ядром, один чеклист на N проектов. Кастом «как по кайфу» не закрываем.

**Агенту:** кормите `last-attention.md` / Copy Attention Report; в шапке дисклеймер — unknown всё равно разбирать самому.
